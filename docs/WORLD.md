## 1. 世界観とぴよ

### 1.1 一行定義
姪っ子（4〜5歳）が **あそぶ → 知育課題をクリア → ⭐がたまる → 街（ランチャー）が確定的に育つ → 新しい飾り・住人が増える**。
相棒 **🐥ぴよ** が「次に楽しいもの」を **1つだけ** 指す。文字は最小、罪悪感なく終われる。

### 1.2 「子ども版どうぶつの森」— 世界の芯
街はゲームである前に、**4〜5歳の発達段階に最適化された安全地帯（secure base）**である。この年齢の子は「選べない・始められない・止められない・数えられない」。街とぴよが、この4つを大人として肩代わりする。**射幸性・競争・喪失は害なので、機能ではなく“構造”から排除する**。

### 1.3 層の分離（不変条件）
| 層 | 実体 | 役割 |
|---|---|---|
| **街＝メタ層** | ランチャー `index.html` 単体 | 進行・愛着・報酬。世界の“家” |
| **施設＝既存アプリ** | 🌳こうえん＝おつかいめいろ／🍰ケーキやさん＝ぴよぴよさんすう／🥕やおやさん＝ぴよぴよことば | 実際の知育課題（⭐の発生源） |

**絶対に壊さないもの**：各アプリへの巨大導線（ランチャー機能）と「家族に配るURLは https://kerokero-1245.github.io/ の**1つだけ**」の約束。街の演出はこの導線を**覆い隠してはならない**。

### 1.4 主役キャラ ぴよ 🐥
街の案内役であり相棒。**文字が読めない子の代わりに、指さし・動き・絵文字・音で意思を伝える**。

- **ポジション**：子どもと対等の「弟／妹」。**先生ではない**。命令しない、教えない、誘うだけ。
- **性格**：あかるい・優しい・食いしんぼう・ちょっとせっかち。**失敗・中断・放置を絶対に責めない**。
- **安全基地としての一貫性**：常に肯定的・応答的。不機嫌・催促・悲しみ・罪悪感の植え付けを**見せない**。
- **即時応答**：タップに 0.1〜0.2 秒で反応する。応答の一貫性が「世界は安全」の感覚と愛着を作る。
- **表情パレットは3種のみ**：喜び／落ち着き／眠い。**恐怖・怒り・焦りは出さない**。

## 2. 4〜5歳UX原則

すべての仕様は、この年齢の「できないこと」を街が肩代わりする、という原則から導く。

### 2.1 誘導付き自由 — ぴよは一度に「ひとつ」だけ指す
- 子どもは**いつでも自分の意思で**こうえん🌳／ケーキやさん🍰／やおやさん🥕へ行ける。街を眺めるだけでもよい（自律の保護）。
- ぴよは**同時にひとつの対象だけ**を指す（🐥→対象へ小さくジャンプ／指さし）。**2つ以上を同時に光らせない**（ワーキングメモリの負荷回避）。
- **提案ロジック（確定・乱数なし）**：原則「**⭐が一番少ない施設**」を指し、各アプリを均等に触らせる。最少が並んだら「**前回と違う施設**」へローテーション（`land.lastPointed` で記憶）。次の街の変化まであと少しなら、その施設を優先してよい。
- 子どもが別を選んでも、ぴよは**笑顔で追従**。却下しても否定的反応を返さない。

### 2.2 文字ゼロ原則
- 4〜5歳は未就学で読字が不安定。導線は**アイコン＋短いひらがなのみ**。意味の運搬はぴよの動きに委ねる。
- 許される文言例：「あそぶ」「またあしたね」「みてみて！」「やったね！」。**長文・数字の説明・英字は出さない**。
- ひらがなは**最大8文字程度**まで。

### 2.3 数を「読ませない・数えさせない」
- **数字を大きく出さない**。進行は数値ではなく、**育つ街そのもの**で表現する。
- 進捗メーターを置くなら、次の変化までの残りを**少数のドット（●●●○○）**で示し、subitizing（パッと見で数がわかる小さな量）の範囲＝**5個以内**に収める。**10を超える数量を数字で見せない**。
- ⭐は「貯まる具体物」として、量の感覚（多い／もうすぐ）を身体的に育てる補助線とする。

### 2.4 因果の即時性
子どもは因果の即時性でしか「自分がやった」と理解できない。街の変化は必ず**その場で（街に戻った瞬間に）見せる**。帰宅後にこっそり増やさない。

## 3. コアループと報酬経済

### 3.1 コアループ
```
街にくる → ぴよが1つだけ指す → 施設で遊ぶ → クリアで⭐
        → 街にもどると 何かが増えている！ → もっと遊びたくなる → 🌙またあしたね
```
**狙う感情の順**：あんしん（見慣れた街）→ わくわく（ぴよが誘う）→ たっせい（⭐）→ **おどろき（街が変わった!）** → まんぞく（夜・おやすみ）。
「**街が変わった**」瞬間がループの心臓。**街に戻った時のリアクションを最重要イベント**として作り込む。

**1セッションの理想尺**：1〜2施設で遊び、街の変化を1回見て、🌙で締める。長時間より「またすぐ来たい」を優先。

### 3.2 街の燃料（fuel）
```js
fuel = Number(localStorage['meiro.totalStars']  || 0)
     + Number(localStorage['sansu.totalStars']  || 0)
     + Number(localStorage['kotoba.totalStars'] || 0)
```
- キー欠損・`NaN`・壊れた値はすべて **0** として扱う（読み取りは常に try/catch ＋ `|| 0`、`Number.isFinite` チェック）。
- 施設が増えても燃料は**同じ合計に合流**する（施設ごとの `<app>.totalStars` を fuel に加算）。
- **同じ fuel なら、誰の街も必ず同じ姿**になる（確定進行）。この既視感が「次は◯◯がふえる！」という**予期の喜び**を生む。

### 3.3 確定報酬の原則（射幸性ゼロ）
- **変動報酬（ガチャ・乱数報酬）は全面禁止**。ドーパミン系を刺激し依存と内発的動機の低下（過正当化）を招くため。
- **⭐は絶対に減らない**（喪失回避の不安を作らない）。
- **退行禁止**：fuel が下がっても、既に開いた段階は**消さない**。到達済み最大段階を `land.reachedStage` に単調増加で保存し、表示はそれを使う。

### 3.4 街の発展段階表（⭐しきい値 × 出現物）【正典・確定】

確定進行・**10段階**。序盤は**⭐2で最初の変化**（早い成功体験で「やれば街が応える」因果を最速で学ばせる）、後半ほど間隔を広げる（頻繁すぎる報酬で価値が飽和するのを防ぎ、達成の重みを出す）。出現物は**絵文字＋インラインSVG**で表現、外部素材なし。

| 段階 | 必要fuel(累計⭐) | 前段からの増分 | 出現するもの（例） | 演出価値 |
|---|---|---|---|---|
| 0 | 0 | – | さら地＋🐥ぴよ＋3施設の入口（🌳🍰🥕） | 出発点・安心 |
| 1 | **2** | +2 | 🌱くさ・🌼はな が生える | 「自分で変えた」初体験 |
| 2 | **4** | +2 | 🐤なかまのひよこ 1羽 | 街に命が増える |
| 3 | **7** | +3 | 🌳き・🪑ベンチ | 居場所らしさ |
| 4 | **11** | +4 | 🏠ちいさな いえ＋けむり | 「住人」の予感 |
| 5 | **16** | +5 | 🐰どうぶつ来訪・みち | 賑わい |
| 6 | **21** | +5 | ⛲ふんすい（池） | うるおい |
| 7 | **27** | +6 | 🎠ひろば（メリーゴーラウンド） | 遊びの象徴 |
| 8 | **34** | +7 | 🌈にじ・🎏かざり | 空まで華やぐ |
| 9 | **42** | +8 | 🎡かんらんしゃ | ランドマーク |
| 10 👑 | **50** | +8 | 🎆まつり・ぴよに👑（王様ぴよ） | 集大成・完成のお祝い |

**運用規律**
- しきい値は**昇順の単調増加**。増分列 `2,2,3,4,5,5,6,7,8,8`（合計50）。**「最初は2⭐」「10段階目は約50⭐」は固定**。見た目の追加は可だが、順序と数値の骨格は本表を書き換えない限り変えない。
- 10段階到達後は「まつり＋👑」を**継続状態**にする。以降 fuel が増えても新規段階はなく、街は完成形を保つ。
- 変化の瞬間は必ず**ぴよが跳ねて喜ぶ🐥✨**を添える。

### 3.5 「街が変わった」演出の実装規律
- 判定は **`land.reachedStage`（到達済み最大段階）の比較**で行う（実装準拠）。ページ表示時に
  `displayStage = max(前回の land.reachedStage, 今回の fuel から求めた段階)` を計算し、
  **`displayStage > 前回の land.reachedStage`（＝新しい段階に入った）ときだけ**、
  新しく開いた段階の登場アニメ＋ぴよの歓声を **1回** 再生する。段階が上がっていなければ
  **静かに表示**（同じ演出を再訪のたび繰り返さない）。
- 表示後、`land.reachedStage` を `displayStage` で更新（**単調増加・退行なし**）。
  `land.lastSeenStars` には今回の fuel を記録（前回訪問 fuel の控え。退行防止は reachedStage が担う）。
- 演出は**短く（段階を跨いだ瞬間の1回・数秒）**。連打・再訪でしつこくしない。
- 施設内で街UIを出さない（気づきを「街に戻った時」に集中させる）。

### 3.6 ぴよ リアクション表（文言＋演出）【正典】
口調ルール：**ひらがなのみ・最大8文字程度・語尾はやわらかく（「〜ね」「〜だよ」「わーい」）。命令形・否定語（だめ・ちがう）は使わない。**

| 場面 | セリフ例 | 動き |
|---|---|---|
| 来訪（朝） | 「おはよー」 | ぴょん、と跳ねる |
| 誘導（次の遊び） | 「こっちこっち」 | 施設を指さし、その方へ小刻み |
| ⭐獲得直後 | 「やったね！」 | くるっと回転＋⭐が舞う |
| 街が育つ瞬間 | 「わー ふえた！」 | 目を✨に、両翼ばんざい |
| しきい値まであと少し | 「もうすこし」 | 次の空き地をチラ見 |
| 何もせず放置 | 「ねむいなあ」 | あくび、こっくり |
| 🌙おやすみ | 「またあしたね」 | 目を閉じ、zzz |

## 5. おしまい設計（🌙 夜モード）

4〜5歳は「もう終わり」を自己制御できない。だから街は**気持ちよく終わる出口を常設**する。

- 🌙ボタンは画面隅に**常時表示・いつ押してもOK**。**ペナルティ・スコア・連続日数（ストリーク）は一切なし**（ストリークは「途切れる不安」を生むので禁止）。
- 夜画面に「まだ遊べる」誘導は**出さない**（やり残し感を与えないため）。

**押下時の演出（固定シーケンス）**
| 段階 | 秒 | 演出 |
|---|---|---|
| 1 | 0.0 | 空が夕→夜へグラデーション、星が点く（背景 紺〜紫、灯りがぽつぽつ） |
| 2 | 1.2 | ぴよが巣（📦/🌿）へトコトコ歩く |
| 3 | 2.5 | ぴよが丸まる💤、吹き出し「またあしたね」 |
| 4 | 4.0 | 画面が静かに暗くなり操作停止（**タップで即再開可**） |

- **ぴよの自発的あくび**：一定の連続操作（目安7〜8分相当の操作カウント。時間計測でなくインタラクション量で代替可）でぴよが小さくあくび🥱。強制でも警告でもなく「そろそろいい区切りだよ」という**穏やかな合図**。無視しても何も起きない。
- **翌訪問は必ず朝に戻す**。判定は端末ローカル日付でよい（同期しない）。`land.lastNightDate` に夜にした日付を保存し、日付が変われば朝へ。前回の街の発展は保持（`land.` キーで永続）。「寝て、また朝が来る」規則性が、時間の予測可能性と安心を育てる。

### 6.1 画風の正典 ― シールポップ（確定）

街・各アプリのモチーフは、絵文字から**自作SVGステッカー「シールポップ」画風**へ移行する。見本は `piyo-assets/reference/style-samples.html` の「シールポップ」セクション（太い白フチ＋濃い輪郭・はっきりした色。ステッカー／LINEスタンプ風でよく目立つ）。

- **素材リポジトリ**：https://github.com/kerokero-1245/piyo-assets （全78モチーフ・`svg/<id>.svg`・`INDEX.md` にid⇔用途の対応表）。各サイトは必要分を自リポジトリの `assets/img/` に**コピーして同梱**し、`<img>`（またはCSS背景）で表示する。**クロスオリジン参照は禁止**（§8・§9＝外部送信/外部依存ゼロ）。

- **全モチーフ自作の方針【確定】**：外部素材（Kenney 等）は審査のうえ**不採用**。ぴよ／街／各アプリのキャラは**すべて自作SVG**で揃える。
- **差し替えの不変条件**：移行は§9「絵文字→将来のAI画像移行規約」に準じ、**絵文字と同じ配置スロットで差し替え、レイアウト・タップ領域・キー・進行表（§3.4）は一切変えない**。素材に無いモチーフは絵文字のまま残してよい。

## 7. localStorage キー台帳【正典】

| キー | 型 | 所有 | 扱い |
|---|---|---|---|
| `meiro.stars` | JSON配列 | めいろ | 既存・**変更禁止**（クリア済み難易度テンプレid） |
| `meiro.celebratedAll` | フラグ | めいろ | 既存・**変更禁止**（全クリア祝福済み） |
| `meiro.totalStars` | 数値文字列 | めいろ | **今回めいろに新設**。クリア毎に +1（**再クリアも +1**）。初期化時は既存 `meiro.stars` の**件数を初期値にマイグレーション** |
| `sansu.totalStars` | 数値文字列 | さんすう | 既存・**変更禁止**（累計クリア回数） |
| `sansu.maxSum` | 設定 | さんすう | 既存・**変更禁止** |
| `kotoba.totalStars` | 数値文字列 | ことば | 既存・**変更禁止**（累計クリア回数）。🥕やおやさんの⭐源。街は**読むだけ** |
| `land.reachedStage` | 数値文字列 | 街 | 到達済み**最大段階（0〜10）を単調増加**で保存。退行防止・「街が変わった」判定（§3.5）に使う |
| `land.lastSeenStars` | 数値文字列 | 街 | **前回訪問時の fuel** の控え（記録用。退行防止は `land.reachedStage` が担う） |
| `land.lastNightDate` | `YYYY-MM-DD` | 街 | 🌙にした日付。朝戻し判定（日付が変われば朝へ） |
| `land.lastPointed` | `park`/`cake`/`shop` | 街 | ぴよが**前回指した施設**。最少⭐が並んだときの誘導ローテーション（§2.1）に使う |

**規約**
- 街用キーは必ず `land.` プレフィックス。読むのは `meiro`/`sansu`/`kotoba` の `totalStars`、書くのは `land.*` のみ。
- **街から他アプリのキーへ書き込み禁止（読むだけ）**。書いてよいのは `land.*` のみ。
- 読み取りは常に try/catch ＋ `|| 0`。キーが無い/壊れている場合も**必ず安全に0扱いでレンダリング**する。
- 燃料の定義（再掲）：`fuel = Number(meiro.totalStars||0) + Number(sansu.totalStars||0) + Number(kotoba.totalStars||0)`。

## 8. データ・プライバシー原則

- 保存は **localStorage のみ**。**個人情報・アカウント・解析トラッカーなし。外部送信ゼロ**。
- データは**消えてよい**（MVPは同期なし）。消失で壊れず、**fuel=0 の初期状態から安全に立ち上がる**こと。
- 破壊的操作（全消去等）を**子の導線に置かない**。
- **決定的であること**：同じ入力（fuel）で同じ街を描く。乱数配置をするなら**種を固定**し再現可能に。

  4. 生成物のライセンス・再現プロンプトを `assets/` にメモ
