# ぴよぴよランド 🐥

4歳の姪っ子のための、あそびの入口（ランチャー / ポータル）ページ。
スマホのホーム画面にこの1つのURLを追加しておけば、開くだけで2つのゲームを選べます。

**公開URL: https://kerokero-1245.github.io/**

## このページの役割

ビルド不要の静的ページ（`index.html` 1枚に CSS/SVG をインライン、JSなし）です。
GitHub Pages の **ユーザーサイト**として、`main` ブランチ直下の `index.html` が
そのままルートURLで配信されます。

- 画面いっぱいの大きなカード2枚（絵文字＋ひらがな）
- 縦持ちスマホ最優先。横持ち・横長画面でも崩れない
- 見た目は2つのアプリと統一（クリーム背景・オレンジ・角丸・やわらかい影）
- リンクは同一タブ遷移。iOSの「ホーム画面に追加」からでもアプリ内に留まりやすい

## 2つのアプリへのリンク

| ゲーム | 内容 | URL |
| --- | --- | --- |
| 🍎 おつかいめいろ | めいろでプログラミング的思考の下地を遊ぶ | https://kerokero-1245.github.io/otsukai-meiro/ |
| 🔢 ぴよぴよさんすう | キャラクターの増減で たしざん・ひきざん | https://kerokero-1245.github.io/piyopiyo-sansu/ |

## 姪っ子への配布手順

1. このURLをLINEで送る → **https://kerokero-1245.github.io/**
2. スマホでリンクを開く
3. ブラウザの共有メニューから「**ホーム画面に追加**」
4. 追加された 🐥 の「ぴよぴよランド」を開くと、2つのゲームを選べます

## 見た目のカスタマイズ

`index.html` の `:root` にある CSS変数（`--bg` / `--orange` / `--green` など）と、
見出しテキスト「ぴよぴよランド」を書き換えるだけで調整できます。
配色は `otsukai-meiro/src/theme.ts` / `piyopiyo-sansu/src/theme.ts` に合わせています。
